# Glossary.md — Istilah Sastra & Teknis

Glosarium istilah yang digunakan di proyek **Lorong Susastra — Digitalisasi Sejarah Sastra Jawa Timur**.

---

## 1. Istilah Sastra / Akademik

| Istilah | Penjelasan |
|---------|------------|
| **Digitalisasi Sejarah Sastra Jawa Timur** | Nama Tugas Besar; judul browser halaman utama |
| **Lorong Susastra** | Brand/identitas website |
| **Sastra Jawa Timur** | Khazanah karya sastra yang lahir/berkembang di wilayah Jawa Timur |
| **Periodisasi** | Pendekatan mengelompokkan perkembangan sastra berdasarkan rentang waktu, memperhitungkan perubahan sosial, budaya, sejarah, dan estetika tiap periode |
| **Resepsi** | Pendekatan mengkaji bagaimana karya sastra diterima, dipahami, dimaknai, dan diinterpretasikan pembaca/masyarakat lintas ruang & waktu |
| **Dramaturgi** | Ilmu/seni penyusunan dan penulisan naskah drama |
| **Prosa** | Karya sastra berbentuk naratif (cerita), mis. novel, cerpen, roman |
| **Puisi** | Karya sastra berbentuk lirik/berirama dengan pilihan kata padat |
| **Puitika** | Kajian tentang prinsip-prinsip keindahan/penciptaan puisi |
| **Pramoedya Ananta Toer** | Tokoh sastra Indonesia (tema inventarisasi karya) |
| **Sastra Cina Peranakan** | Karya sastra dari komunitas peranakan Tionghoa di Indonesia |
| **Aming Aminoedhin** | Tokoh/penyair Jawa Timur (karya dalam kajian resepsi) |
| **Digitalisasi** | Proses mengubah dokumen/karya cetak menjadi bentuk digital |

## 2. Istilah Teknis / Struktur

| Istilah | Penjelasan |
|---------|------------|
| **Landing page** | Halaman utama/beranda yang menampilkan ringkasan seluruh konten |
| **Accordion** | Komponen UI berisi panel yang membuka/menutup untuk menghemat ruang |
| **Panel** | Satu bagian dalam accordion (nomor + kategori + judul + tautan) |
| **Sidebar** | Panel navigasi di kiri sub-halaman |
| **Submenu** | Daftar artikel yang muncul saat kategori dibuka |
| **Pagination** | Navigasi halaman/konten (prev, dot, next) |
| **Deep-link** | Tautan yang langsung membuka konten tertentu via query string (`?category=&id=`) |
| **Viewer PDF** | Komponen untuk menampilkan file PDF di browser |
| **PDF.js** | Library JavaScript dari Mozilla untuk render PDF |
| **Design token** | Variabel CSS untuk warna/ukuran agar konsisten |
| **Dark mode / light mode** | Tema gelap / terang |
| **Custom cursor** | Kursor khusus yang menggantikan kursor bawaan OS |
| **ES Module** | Standar modul JavaScript (`<script type="module">`) |
| **Query string** | Bagian URL setelah `?` yang membawa parameter |
| **localStorage** | Penyimpanan persisten di browser (dipakai untuk tema) |
| **Clamp()** | Fungsi CSS untuk ukuran responsif (`clamp(min, preferred, max)`) |

## 3. Singkatan yang Dipakai di Kode

| Singkatan | Kepanjangan |
|-----------|-------------|
| `UNAIR` | Universitas Airlangga |
| `NIM` | Nomor Induk Mahasiswa |
| `CTA` | Call to Action (tombol ajakan) |
| `CTA` ikon | `ri-*` = Remixicon icon |
| `id` (data) | Identifier artikel per kategori |
| `slug` | Format label untuk URL (`drama`, `komunitas`, `prosa`, `puisi`) |

## 4. Istilah Tim (Footer Cover Page)

| Istilah | Penjelasan |
|---------|------------|
| **Dosen Pengampu** | Dosen yang mengampu/bertanggung jawab mata kuliah/kelas |
| **Disusun Oleh** | Daftar anggota kelompok penyusun |
| **Cover page** | Halaman sampul (di footer) berisi identitas institusi & tim |
